\doxysubsection{Detailed Description}
The \doxylink{classAIAgent}{AIAgent} interface describes the behavior of any implemented Artificial Intelligence agent. 

This abstract base class inherits from \doxylink{classPlayer}{Player} and establishes a common interface for all AI agents (such as \doxylink{classMiniMaxAgent}{Mini\+Max\+Agent}). It defines the basic functions necessary for an agent to reset its internal state before a new turn or game.
