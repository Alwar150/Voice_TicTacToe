\doxysubsection{Detailed Description}
The \doxylink{classPlayer}{Player} class is an abstract base class for different types of players. 

This class defines the common interface for all participants in the Tic-\/\+Tac-\/\+Toe game, whether they are human players (\doxylink{classHumanPlayer}{Human\+Player}), AI agents (\doxylink{classMiniMaxAgent}{Mini\+Max\+Agent}), or network players. It provides the mechanism to start the turn ({\ttfamily \doxylink{classPlayer_af85db5d05b014bf19d873038c56dc7ed}{play()}}) and notify the completed move.
