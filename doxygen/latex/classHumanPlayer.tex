\doxysubsection{Detailed Description}
The \doxylink{classHumanPlayer}{Human\+Player} class represents the human player in the game. 

Inherits from the abstract base class \doxylink{classPlayer}{Player}. It is responsible for capturing user input (either through GUI clicks or, in this case, through voice recognition using \doxylink{classSpeechManager}{Speech\+Manager}) and converting it into a valid move on the board.

Uses a dedicated worker thread ({\ttfamily QThread}) for voice processing ({\ttfamily \doxylink{classSpeechManager}{Speech\+Manager}}) to avoid blocking the main GUI thread.
