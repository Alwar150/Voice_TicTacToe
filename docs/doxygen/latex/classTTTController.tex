\doxysubsection{Detailed Description}
The \doxylink{classTTTController}{TTTController} class acts as the controller (C in MVC) for a Tic-\/\+Tac-\/\+Toe game. 

\doxylink{classTTTController}{TTTController} manages the interaction between the user interface (the View, \doxylink{classTicTacToeGame}{Tic\+Tac\+Toe\+Game}), the game state (the Model, \doxylink{classBoard}{Board}) and the game logic, including turn management, AI agents (\doxylink{classMiniMaxAgent}{Mini\+Max\+Agent}), human players and network communication (\doxylink{classNetworkManager}{Network\+Manager}). It is responsible for receiving game options and orchestrating the game flow.
