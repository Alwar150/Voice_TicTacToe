\doxysubsection{Detailed Description}
The \doxylink{classConfigManager}{Config\+Manager} class manages the application configuration. 

Manages the application configuration from a config.\+ini file. Applies the {\bfseries{Singleton}} pattern to ensure only one globally accessible instance exists, providing a centralized point to access program options.
